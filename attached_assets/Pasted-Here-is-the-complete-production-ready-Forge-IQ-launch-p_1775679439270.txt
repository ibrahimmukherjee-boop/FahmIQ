## Part 1: Master Replit Build Prompt

This is the exact verbatim prompt to paste into Replit Agent. It covers:

### Architecture
The app uses **React Native + Expo SDK 52** with Expo Router, targeting iOS 17+ only, built and submitted via **EAS Build** — Replit's native mobile workflow now supports this end-to-end. [docs.replit](https://docs.replit.com/updates/2026/01/16/changelog)

### The Cognitive Neuroscience Engine
Every agent module maps to a real neuroscience model, making the quality layer scientifically defensible:

| Neuro Principle | Module | What it does |
|---|---|---|
| Dual-Process Theory | `DualProcessRouter.ts` | Ask = System 1 (fast), Deep Task = System 2 (deliberate) |
| Working Memory | `WorkingMemoryBuffer.ts` | Prunes context to capacity limits per model band |
| Spreading Activation | `SpreadingActivation.ts` | Expands user input semantically before Worker pass |
| Selective Attention | `AttentionGating.ts` | Scores context fragments for relevance, top-K selection |
| Metacognition | `MetacognitiveMonitor.ts` | Tracks confidence 0.0–1.0, triggers repair loop if < 0.72 |
| Predictive Coding | Scout UI layer | Shows predicted output type while pipeline runs |

### The 4-Band Agent Pipeline
- **Scout** (Qwen2.5-0.5B, Fast): intent parsing, routing, concept extraction [reddit](https://www.reddit.com/r/LocalLLM/comments/1sbf6vs/experimenting_with_mlcllm_tvm_on_ios_i_built_an/)
- **Worker** (user's selected band, Qwen2.5-1.5B): main generation pass [blog.devstory.co](https://blog.devstory.co.kr/en/post/mlc-llm-ios/)
- **Critic** (Qwen2.5-0.5B, Fast): adversarial review across 5 scored dimensions [runanywhere](https://www.runanywhere.ai/blog/best-ai-platforms-local-llms)
- **Judge** (Qwen2.5-1.5B, Balanced): final synthesis + confidence-tagged answer [runanywhere](https://www.runanywhere.ai/blog/best-ai-platforms-local-llms)

The repair loop fires if Critic aggregate score is below 0.72, running Worker again with targeted repair instructions — this is the core quality mechanism that makes outputs demonstrably more reliable than a single-pass LLM call. [blog.devstory.co](https://blog.devstory.co.kr/en/post/mlc-llm-ios/)

### Two Runtime Modes
- **Mock runtime** (instant, no native bridge needed): app is 100% functional and App Store submittable from day one [docs.replit](https://docs.replit.com/updates/2026/01/16/changelog)
- **MLC LLM native bridge** (post-MVP): real on-device inference with Qwen2.5 quantised models via MLC LLM iOS runtime, the most production-ready path for local iOS LLM deployment in 2026 [blog.devstory.co](https://blog.devstory.co.kr/en/post/mlc-llm-ios/)
