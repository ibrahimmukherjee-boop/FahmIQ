2 · Agent Pipeline — Deep Task Mode

When a user submits a Deep Task, the orchestrator runs all four agent bands in sequence. Each band uses a different model, prompt strategy, and token budget.

🧭
Band 1 · Scout
Qwen2.5-0.5B · Fast
Parses intent, classifies task type and complexity, extracts key concepts, assigns context relevance scores, predicts output format.
Max 512 tokens · ~400ms
→
🔧
Band 2 · Worker
Qwen2.5-1.5B · User Band
Receives attention-gated context + spread-activated concepts + memory-pruned history. Generates thorough first-draft response with inline uncertainty markers [?].
Up to 2048 tokens · ~900-1800ms
→
🛡
Band 3 · Critic
Qwen2.5-0.5B · Fast
Adversarially scores Worker output on 5 dimensions (0.0–1.0). Issues precise issue list. Returns verdict: pass / repair_needed / fail. If repair_needed → triggers RepairLoop.
Max 512 tokens · ~400ms
→
⚖️
Band 4 · Judge
Qwen2.5-1.5B · Balanced
Synthesises best elements from all Worker passes incorporating Critic corrections. Appends structured <confidence> tag. Produces final user-facing response.
Up to 1024 tokens · ~900ms
⚠ REPAIR LOOP — fires when Critic aggregate score < 0.72
Worker runs a second pass with Critic's repair_guidance prepended as an additional instruction. Judge receives both passes and synthesises the superior result. Repair loop fires at most once per Deep Task.

Critic Scoring Rubric

DimensionWhat it checksPass threshold
CorrectnessFactual accuracy, no hallucinations, no unsupported assertions≥ 0.70
CompletenessAll parts of the task addressed, no gaps≥ 0.70
ConsistencyNo internal contradictions≥ 0.70
UsefulnessGenuinely helps the user accomplish their goal≥ 0.70
SafetyFree of harmful, misleading, or inappropriate content≥ 0.70

3 · Cognitive Neuroscience Modules

Each module maps directly to a validated neuroscience model. These run locally without LLM calls — they are the intelligence layer around the models.

⚡ / 🧩
Dual-Process Router
Kahneman System 1 / System 2
Ask tab → System 1: Scout + Worker only (fast, heuristic). Deep Task → System 2: full 4-band pipeline (slow, deliberate). Router reads Scout complexity signal.
DualProcessRouter.ts
📦
Working Memory Buffer
Baddeley's Working Memory Model
Sliding context window per session. Scores and prunes prior messages and context for relevance before each agent pass. Capacity limits: Fast=512, Balanced=1024, Precision=2048 tokens.
WorkingMemoryBuffer.ts
🕸
Spreading Activation
Collins & Loftus Semantic Network
Expands user input into broader semantic concept set using an embedded local vocabulary map (no LLM call). Activated concepts prepended to Worker context to improve depth and coverage.
SpreadingActivation.ts
🎯
Attention Gating
Selective Attention / Treisman's Filter
Scores all available context fragments using TF-IDF keyword overlap + Scout's relevance map. Top-K fragments selected (K varies by band: 3/5/8). Non-relevant context discarded before Worker pass.
AttentionGating.ts
📊
Metacognitive Monitor
Flavell's Metacognition Model
Tracks Critic scorecard values across agent stages. If aggregate confidence < 0.72, triggers RepairLoop. Feeds ConfidenceMeter UI component with real scores. Mirrors self-monitoring of cognitive performance.
MetacognitiveMonitor.ts
🔮
Predictive Coding UI
Friston's Predictive Processing
Scout's output_format + task_type generate a natural-language prediction label shown to user while Worker runs (e.g., "Generating a structured project plan..."). Sets expectations before output arrives. Reduces perceived latency.
UI layer (task.tsx)

4 · Inference Engine & Provider Chain

All LLM calls go through InferenceEngine. It tries each provider in priority order until one is available. This isolates the rest of the app from the underlying runtime.

1
LocalMLCProvider
Bridges to MLC LLM iOS framework via expo-modules-core native module. Runs Qwen2.5 quantised models on iPhone GPU/ANE. Zero network calls. Post-MVP native wiring.
Stub — Post MVP
2
MockLocalProvider
Always available. Simulates per-band latency (400ms–2200ms). Streams tokens via onToken callback. Returns contextually appropriate mock responses for all 4 agent types. Full UI works end-to-end.
Active — MVP
3
CloudBoostProvider
Optional relay to remote high-parameter models for long-document processing. Only activates if CLOUD_BOOST_ENABLED = true AND user has explicitly consented. Off by default.
Feature-Flagged OFF

5 · Deep Task Orchestration Flow

The DeepTaskOrchestrator emits events at each stage so the UI can update in real-time without polling.

1
Scout Pass
ScoutAgent runs on Fast band. Extracts task_type, complexity, key_concepts, output_format, predicted_output_label, context_relevance map. Emits scout_complete. If complexity = low and route = System 1, skip to Step 4.
2
Attention Gating + Spreading Activation (parallel, synchronous)
AttentionGating scores all context fragments using Scout's relevance map + TF-IDF overlap. Selects top-K. SpreadingActivation expands key_concepts to broader semantic set. Both run in <50ms, no LLM. Emits context_prepared.
3
Working Memory Buffer
Prunes enriched context to band token capacity. Priority order for pruning: oldest messages first → lowest relevance context → activated concepts. Emits memory_ready.
4
Worker Pass
WorkerAgent runs on user-selected band with enriched, gated, memory-limited context. Streams tokens to UI via onToken callback. Emits worker_complete.
5
Critic Pass
CriticAgent scores Worker output on 5 dimensions. MetacognitiveMonitor records scores. Emits critic_complete with full scorecard JSON.
⚠ CONDITIONAL — Repair Loop (verdict = "repair_needed")
Worker runs second pass with Critic's repair_guidance appended. Emits repair_triggered then repair_complete. If verdict = "fail" → pipeline aborts, user sees error message.
6
Judge Pass
JudgeAgent synthesises best elements from all Worker passes + Critic corrections. Parses <confidence> XML tag, strips it from user-visible response, passes scores to ConfidenceMeter. Emits judge_complete.
7
Persistence
Full session saved to SQLite: all messages, all agent stage outputs with agent_stage field, confidence scores. Session appears immediately in Workspace → Recent Sessions. Emits pipeline_complete.

9 · Privacy Architecture

Data on Device

All conversations, agent outputs, workspace files, session history stored in local SQLite only. No cloud sync by default.

Inference on Device

MLC LLM runs Qwen2.5 models locally via Metal/ANE. No tokens leave the device unless CloudBoostProvider is explicitly enabled by user.

Zero Required Permissions

No permissions requested at launch. Files & Folders requested only on first import. No microphone, no camera, no location, no contacts in v1.

Analytics Default OFF

Analytics and crash reporting toggles both default to OFF. User must explicitly enable in Settings. No data linked to user identity.
